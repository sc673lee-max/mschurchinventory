3. 물품 대여 및 반납 가이드

3.1 물품 대여 / 사용 등록 (★ 필수 입력 사항)

주일 공과, 예배, 부서 행사 준비를 위해 물품을 가져갈 때는 반드시 시스템에 대여 등록을 진행합니다.

  1. 홈 화면의 [대여 / 사용 등록] 버튼 또는 물품 목록에서 원하는 물품 클릭 후 [대여 / 사용 등록]을 누릅니다.
  2. 다음 항목들을 입력합니다:
    • 대여 물품 *: 대여할 물품 선택 (재고가 1개 이상 남아있는 물품만 선택 가능)
    • 수량 *: 대여할 수량 입력 (현재 가용 재고 초과 불가)
    • 사용 부서 *: 물품을 사용하는 부서명 입력 (예: 영아팀, 유아팀, 유치팀, 통미팀, 초등1팀 등)
    • 담당자 성명 *: 대여하는 교사 또는 담당자 성함 (예: 김철수 선생님)
    • 픽업 예정일 *: 물품을 가져가는 날짜
    • 반납 예정일 *: 다시 보관 장소에 가져다 놓을 기한 (기본값: 픽업일로부터 7일 뒤)
  3. [등록 완료]를 누르면 즉시 가용 재고가 차감되고 대여 목록에 반영됩니다.

3.2 일반 물품 vs 일회용품(소모품) 대여 차이

[물품 구분 및 처리 흐름]
├── 1. 일반 대여 물품 (마이크, 보드게임, 악기, 음향장비 등)
│   └── ⚠️ 사용 후 반드시 정해진 기한 내에 반납 처리해야 함 (반납 예정일 관리)
│
└── 2. 일회용품 / 소모성 물품 (종이컵, 도화지, 스티커, 건전지 등)
    └── ✅ 1회 사용 후 소모/폐기되므로 반납 절차가 불필요함
    └── 대여 창에서 일회용품 선택 시 '소모성 물품'이 자동으로 체크되며,
        반납 예정일 입력란이 숨겨지고 즉시 소모 완료 처리됩니다.
💡 팁: 일반 물품이라도 행사 중 파손되거나 영구 소모되는 특수한 상황에는 교사가 직접 [소모성 물품] 체크박스를 체크하여 반납 절차를 생략할 수 있습니다.

3.3 물품 반납 완료 처리

물품 사용을 마치고 원래 보관 장소에 되돌려 놓은 후에는 시스템에 반납 처리를 해주셔야 다른 선생님들이 사용할 수 있습니다.

  1. 하단 [대여 현황] 탭 ➡️ [대여 중] 또는 [연체] 목록으로 이동합니다.
  2. 본인이 대여한 물품 카드를 찾습니다.
  3. [반납 완료] 버튼을 누르면 즉시 반납 완료 처리되며, 가용 재고가 원래대로 복구됩니다.

4. 물품 등록 및 수정 가이드

4.1 새 물품 등록 (사진 촬영 vs 갤러리 선택)

새로운 비품이나 교구, 교재를 구입했거나 기증받았을 때 등록하는 방법입니다.

  1. [물품 목록] 탭 우측 하단의 `+` 플로팅 버튼 또는 홈 화면의 [새 물품 등록]을 누릅니다.
  2. 사진 등록 (선택):
    • 📷 사진 촬영: 스마트폰 카메라가 즉시 켜져 물품 실물을 그 자리에서 바로 촬영합니다.
    • 🖼️ 갤러리 선택: 카메라 대신 사진 앨범/갤러리가 열려 저장되어 있던 사진을 선택합니다.
    ※ 사진을 등록한 후에도 [📷 다시 촬영], [🖼️ 갤러리 변경], [사진 삭제] 버튼으로 손쉽게 바꿀 수 있습니다.
  3. 물품 정보 입력:
    • 물품 이름 *: 구분하기 쉬운 명칭 (예: 유아용 색연필 24색)
    • 카테고리: 분류명 (예: 미술용품, 악기, 교재, 행사용품)
    • 관리 / 등록 부서: 물품을 관리하거나 구매한 부서 (예: 유치팀, 초등1팀)
    • 등록자 성명: 등록한 담당자 이름 (예: 이영희 교사)
    • 보관 장소 *: 물품이 보관될 장소 선택
    • 보유 수량 *: 최초 총 보유 수량
    • 일회용품 체크 (선택): 1회 사용 후 폐기/소모되는 물품인 경우 체크
  4. [등록 완료]를 누르면 물품이 등록됩니다.

4.2 물품 정보 수정 및 사진 변경/삭제

물품 상세 모달에서 [정보 수정]을 누르면 이름, 카테고리, 부서, 등록자, 보관 장소, 총 수량 및 사진을 언제든지 수정할 수 있습니다.

4.3 재고 입고 (추가 수량 등록)

기존 물품을 추가로 구입하여 수량이 늘어난 경우, 물품 상세 모달에서 [재고 입고] 버튼을 눌러 추가 수량만 입력하면 기존 재고에 자동 합산됩니다.

5. 물품 및 재고 개별 삭제 가이드

과거에는 반납 안 된 대여 물품이 있으면 삭제가 전면 차단되었으나, 현재는 대여 물품과 남아 있는 재고를 각각 분리하여 개별 삭제할 수 있습니다.

5.1 대여 중인 물품 개별 삭제

빌려간 사람이 물품을 분실/파손하여 돌려받을 수 없거나, 잘못 대여 등록한 건을 정리할 때 사용합니다.

  • 위치: 대여 카드 또는 물품 상세 모달 내 대여 목록의 [대여 삭제] 버튼 클릭
  • 삭제 방식 선택:
    1. 🗑️ 대여 물품 영구 삭제 (재고 폐기): 물품이 파손·유실되어 더 이상 존재하지 않을 때 선택합니다. 대여 기록이 삭제되며 총 보유 수량(totalQty)에서도 영구 차감됩니다.
    2. ↩️ 대여 등록 취소 (재고 복구): 잘못 등록한 대여 건을 취소하고 해당 수량을 다시 가용 재고(availableQty)로 반환합니다.

5.2 보관 중인 남아 있는 물품 개별 삭제

보관 중이던 재고가 낡아서 폐기 처분해야 할 때 사용합니다.

  • 물품 상세 모달 ➡️ '현재 가용 재고' 우측의 [남은 물품 삭제] 빨간색 버튼을 누릅니다.
  • 확인 후 보관 중인 잔여 재고만 0개로 폐기 삭제되며, 현재 대여 중인 물품은 그대로 유지됩니다.

5.3 물품 전체 일괄 삭제

물품 상세 창 하단의 [물품 전체 삭제]를 누르면, 대여 중인 물품이 있더라도 확인 후 대여 건과 잔여 물품을 모두 포함하여 시스템에서 완전히 일괄 삭제할 수 있습니다.

6. 물품 분실 신고 및 재고 복구

6.1 분실 신고

대여 중이거나 보관 중인 물품이 분실되었을 때 신고하여 정확한 자산을 관리합니다.

  • 대여 카드의 [분실 신고] 또는 [대여 현황] ➡️ [분실 내역] ➡️ [+ 직접 분실 신고]
  • 분실 수량, 사유, 확인 담당자를 입력하여 신고하면 총 보유 수량에서 자동 차감됩니다.

6.2 분실 물품을 다시 찾았을 때 (재고 복구)

시간이 지나 분실 처리했던 물품을 다시 찾은 경우:

  • [대여 현황] ➡️ [분실 내역]으로 이동하여 해당 기록 우측의 [재고 복구] 버튼을 누릅니다.
  • 차감되었던 수량이 시스템의 총 보유 수량 및 가용 재고로 즉시 정상 복원됩니다.

7. 자주 묻는 질문 (FAQ)

Q1. 사진 등록 시 갤러리(앨범)가 안 열리고 카메라만 켜져요.
새 물품 등록 창 상단에 [📷 사진 촬영]과 [🖼️ 갤러리 선택] 두 개 버튼이 구분되어 있습니다. 반드시 [🖼️ 갤러리 선택] 버튼을 누르시면 앨범에서 사진을 선택하실 수 있습니다.
Q2. 일회용품(종이컵, 도화지 등)은 반납 처리를 어떻게 하나요?
일회용품은 1회 사용 후 소모되므로 반납 처리를 하실 필요가 없습니다. 대여 시 자동으로 소모 처리되며, [대여 현황] ➡️ [소모 내역]에서 이력을 확인할 수 있습니다.
Q3. '대여 / 사용 등록' 버튼을 눌렀는데 등록이 안 돼요.
대여 물품, 수량, 사용 부서, 담당자 성명 4가지 필수 항목이 모두 채워졌는지 확인해주세요. 비어 있는 항목이 있으면 안내 알림이 표시됩니다.
Q4. 실수로 대여 등록을 눌렀는데 어떻게 취소하나요?
[대여 현황] 탭에서 해당 카드의 [대여 삭제]를 누른 후 '↩️ 대여 등록 취소 (재고 복구)'를 선택하시면 재고가 원상태로 복구됩니다.
Q5. 상단의 동기화 표시가 주황색(로컬 저장 모드)으로 떠요.
인터넷 연결이 원활하지 않을 때 로컬에 임시 저장됩니다. 인터넷이 연결되면 자동으로 다시 초록색 [클라우드 동기화 중]으로 전환되어 안전하게 서버에 동기화됩니다.
